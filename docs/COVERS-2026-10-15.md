# 首页与技能封面 · 2026-10-15

本轮范围：保留现有品牌与静态站架构；不改智能合约、不上传文件、不引入收费资源。

## 实现
- 首页展示最新四条待接单需求，入口显示当前网络的真实待接单总量。
- 技能入口明确“查看全部技能”，标明包含示例和本机发布内容。
- 发布技能时可选作品集图片、公开 HTTPS 图片直链或分类默认封面。
- 可调水平/垂直取景，预览同步；支持恢复自动封面，图片失败回退分类图形。
- 封面 URL 和取景位置保存在技能资料中，并随原有编码分享链接携带。
- 限定自定义封面 HTTPS、拒绝带账号密码的 URL、转义属性、数值取景限制 0–100。

## 真实边界
- 技能列表仍仅保存当前浏览器，不是全站持久化目录；分享链接可在另一浏览器显示同一封面。
- 链接内的技能内容不是签名身份认证。既有技能雇佣机制未改变。
- 不提供本地图片上传、服务端图片存储或需求封面修改；这些需免费后台及授权模型就绪后实现。
- 外部图片由原图站点提供，可失效或被修改；没有服务端代理、版权鉴定或文件哈希认证。
- 需求封面后续：网络+订单 ID 关联、发布者钱包签名鉴权、共享存储、类型/尺寸限制、替换/删除权限；不改订单协议。

## 验证
本地浏览器验证通过：作品图选择、25%/75% 取景、新浏览器分享、加载失败回退、非法 URL 拦截、恢复默认、390px 无横向溢出。隔离 L1 配置回归通过：20/30 阶段交付、V2 历史、验收放款、零 Gas 拦截与补充测试 Gas 后领取。未重新执行真实钱包、公链资金交易或外部图床验收。测试退出码为 0；Ganache 原生模块使用 JS 回退，测试进程还输出监听器数量警告。
